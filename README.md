One line, 140 characters, in the office printer's own voice: a flat error log that counts every jam and turns the blame back on the humans staring at it — it has printed your resignation letter three times this year, and you still work here. The program in `main.py` writes that line to `entry.txt` in the output directory. It is a two-beat micro-story in document/log framing: a literal maintenance record, then a single hard reversal in the final clause.

## Run it

```sh
python3 main.py
```
